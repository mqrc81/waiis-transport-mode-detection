### Data Input

* Shape and channel order: X.npy is `(samples, length, 6 × joints)`, with acc xyz then gyro xyz for each joint, in
  --joint_list order.
* Rate: Pass `--original_sampling_rate=25`; the loader resamples to 20 Hz
* No normalization in the loader => export must already be in m/s^2 & rad/s
* y.npy with shape `(samples,)` and a JSON file with the label names required
    * Open question: In zero-shot mode the label names are the text prompts the model compares against, so the wording
      (“car” vs “riding in a car” vs “driving”) can change the result
