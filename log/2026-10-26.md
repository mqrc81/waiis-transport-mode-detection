## Experiment 02: LightGBM + HMM baseline on SHL + ExtraSensory

*(Details in `experiments/02_family-baseline_shl-es/README.md`; runs in MLflow `02_family-baseline_shl-es`.)*

**Setup**

- 25 Hz (uniform 100 Hz grid → FIR decimation), 5 s windows, 2.5 s stride.
- Features v1: 145 = 5 orientation-independent channels (|a|, vertical a, horizontal |a|, |ω|, jerk) × 29
  (stats, ACF, Hjorth, Welch bands 0–1 / 1–3 / 3–6 / 6–12.5 Hz, spectral entropy).
- LightGBM, fixed hyperparameters, balanced class weights, rounds from early stopping on an inner fold; one seed.
- Splits: SHL User 1 in 5 day-folds; ExtraSensory 48 dev users in 5 user-folds. 12 ES test users untouched.

### 1. R1: trained on SHL only

- SHL out-of-fold: macro-F1 0.755 (8 classes) / 0.842 (family).
- ExtraSensory as unseen dataset: 0.259 / 0.320.
- 65% of ES still predicted as rail: phones lying on a table are quieter than anything in SHL.

### 2. ExtraSensory labels v2

- Drop sleeping; drop walk / run / bike when the phone isn't carried; cap not-carried still at 20% per user.
- R1 on ES: family 0.320 → 0.366. Still is still mostly predicted as rail.

### 3. Adding ExtraSensory to training (R2, paired folds)

| trained on | SHL family | ES family (CI over users) | SHL still → rail | ES still → rail |
|------------|------------|---------------------------|------------------|-----------------|
| SHL (R1)   | 0.842      | 0.362 (0.32–0.39)         | 17%              | 55%             |
| ES only    | 0.602      | 0.403 (0.36–0.44)         | 6%               | 3%              |
| SHL + ES   | 0.784      | 0.489 (0.45–0.52)         | 48%              | 7%              |

- R2 fixes ES still (recall 0.25 → 0.75) but costs SHL still and ES rail (0.62 → 0.41).
- ES only barely learns rail (train in 4 users); early stopping stopped it at 7–31 rounds.

### 4. 60 s context + HMM (on R2)

| config           | SHL 8 / family | ES 8 / family |
|------------------|----------------|---------------|
| base (= R2)      | 0.723 / 0.784  | 0.400 / 0.489 |
| base + forward   | 0.837 / 0.879  | 0.476 / 0.566 |
| base + Viterbi   | 0.853 / 0.890  | 0.494 / 0.583 |
| context + Viterbi| 0.891 / 0.930  | (invalid)     |

- HMM (transitions from SHL training days): biggest cheap gain. SHL bus recall 0.56 → 0.85, train 0.58 → 0.77.
  Causal forward filtering is nearly as good as Viterbi.
- Context: the model uses the number of windows in the context as a dataset label (24 on SHL, ~6 on ES),
  so its ES numbers are invalid. SHL numbers stand.
- Car vs bus and train vs subway stay weak across datasets (ES bus recall 0.24).

**Cost:** ~2.2 ms per window in Python (features ~2.1 ms, model 0.03 ms); model 6.95 MB.

### 5. Decision

- 02 parked. Candidate: R2 + HMM Viterbi (SHL 0.853 / 0.890, ES 0.494 / 0.583).
- Next: label-efficiency study.
- Open: context fix (step 3b), ES-only rerun with fixed rounds, ONNX export.
